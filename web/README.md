# MIMIC Web（React + TypeScript）

廠務燈號平台的桌機版網頁設計。燈號：🔴 紅＝異常、🟡 黃＝部分異常、🟢 綠＝正常、⚪ 灰＝無資料；資料來源為 FDM（目前以模擬資料取代）。

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # 燈號判定邏輯單元測試（vitest）
npm run build      # tsc 型別檢查 + 正式建置到 dist/
```

## 頁面與網址

每一頁都有獨立網址（BrowserRouter；正式部署的靜態伺服器需把所有路徑 fallback 到 `index.html`）。

| 網址 | 內容 |
|---|---|
| `/p/overview` | 首頁燈號牆：由「燈號」與「文字」積木組成的畫布（每個廠區 × 系統是一顆系統燈號積木），點燈號下鑽 |
| `/p/:slug/b/:blockId` | 燈號積木的下鑽頁：摘要卡 + 這顆積木選取的 Tag 燈號清單（版面同系統下鑽頁） |
|  | 兩種下鑽頁的 Tag 燈號清單都有 **OOC / OOS** 欄，顯示 FDM 回傳的旗標（TRUE / FALSE，無資料為「—」），讓使用者看到燈號為什麼亮 |
| `/p/:slug/:site/:system` | 下鑽頁：規則說明、Tag name / Description / Value，可切「僅顯示異常 / 全部 Tag」，Refresh Values 重新取值 |
| `/p/:slug/edit` | 編輯模式：積木畫布（左側積木庫）。自建頁面與內建燈號牆頁面共用；內建頁面可「還原預設版面」 |
| `/explore?q=UPW&system=…&site=…&author=…&sort=…` | 搜尋他人頁面、篩選、排序；☆ 加入 / 移除 Favorites（搜尋條件放在網址，可分享） |
| `/p/:slug` | 其他頁面（Favorites 側欄、Explore 結果）；單一廠區 × 系統的頁面直接顯示下鑽內容 |
| `/systems` | 系統管理：系統清單（負責人、各廠區 Tag 數、引用頁面數），新增系統 |
| `/systems/:id` | 編輯系統：基本資料、各廠區的 Tag（向 FDM 檢查後加入）、引用這個系統的頁面、變更紀錄、刪除 |

### 積木

使用者看到的主要呈現都是積木，內建頁面與自建頁面共用同一套（架構與擴充方式見 [`src/blocks/README.md`](src/blocks/README.md)）：

| 積木 | 用途 |
|---|---|
| 燈號 | 選取 Tag，依 FDM 的 isOOS / isOOC 自動亮紅、黃、綠（單顆燈 + 下方一行文字） |
| 文字 | 標題與備註 |
| 燈號牆、系統摘要、Tag 清單 | 目前只用來組成內建下鑽頁，積木庫暫不開放 |

每個積木都有**小 / 中 / 大**三種尺寸，長寬比例 **1 : 2 : 4**。編輯模式下：**點一下積木選取**，工具列固定顯示在積木下方（尺寸切換、編輯、複製、刪除）；雙擊或按「編輯」開啟編輯器，右側以實際大小即時預覽。點空白處或按 Esc 取消選取。

### 燈號積木：只要選 Tag

燈號**不需要設定任何條件**，由 FDM 回傳的旗標決定：

| FDM 回傳 | 燈號 |
|---|---|
| 任一 Tag `isOOS`（超出規格） | 紅 |
| 無 OOS，任一 Tag `isOOC`（超出管制） | 黃 |
| 都沒有 | 綠 |
| 全部沒有資料 | 灰 |

編輯器的資料來源有兩種：

- **選擇 Tag**：
  1. **設定 Tag**：選廠區、輸入 Tag 名稱（可一次貼多個，換行 / 空白 / 逗號分隔，不分大小寫），按「檢查並加入」。FDM 找不到的名稱會列出並保留在輸入框，方便修正；重複的不會再加入。
  2. **選取 Tag**：或從 FDM Tag 清單搜尋點選（已加入的會標示）。
  3. **檢查 Tag 有效**：已選清單顯示每個 Tag 的目前值與 FDM 判定（OOS / OOC / 正常 / 無資料 / 無效）；「重新檢查」會向 FDM 重新取值。無效的 Tag 不計入燈號。
  - 只選一個 Tag 時燈號下方顯示它的數值，選多個時顯示統計（例如「3 台異常」）。
- **整個系統**：選廠區與系統，該系統所有 Tag 一起判定，點燈號下鑽到 Tag 清單。

舊版（自訂算式時期）存下的燈號積木，讀取時只保留選過的 Tag，條件算式不再使用。

### 內建燈號牆也是積木

全廠總覽與各系統頁（Power、UPW、HVAC…）都是由「燈號」與「文字」積木組成的畫布：每個廠區 × 系統是一顆「整個系統」的小燈號（顯示「3 台異常」，點了下鑽），欄名、列名、標題是文字積木。按 **Edit** 就能像自建頁面一樣拖曳、縮放、增刪，修改自動儲存；**還原預設版面**可回到原樣。

### 自建頁面

- 側欄「＋ 新增頁面」（或各分類標題的 ＋）建立空白頁面，進入畫布編輯模式（`/p/u-xxxxxx/edit`）。
- 左側**積木庫**列出所有積木種類，點一下加到畫布；積木可拖曳（對齊 10px 格線）、方向鍵微調、複製、刪除。
- 檢視模式點燈號積木會**下鑽**：「選擇 Tag」的燈號進入這顆積木的下鑽頁（`/p/:slug/b/:blockId`，摘要卡 + Tag 燈號清單）；「整個系統」的燈號進入系統下鑽頁。

### 側欄

- Favorites 旁的 ＋ 是**新增分類**；分類可改名、刪除（頁面會併入相鄰分類，不會消失）。
- **所有頁面（含內建頁面）都能上下調整**：拖曳到任何分類的任何位置，或用滑過時出現的 ↑ ↓ 按鈕（到分類邊界會跨到相鄰分類）。分類本身也能拖曳或用 ↑ ↓ 調整順序。

左側 Favorites 側欄可收合為窄欄、群組可展開 / 收起、群組內可拖曳排序；狀態存在 localStorage。燈號牆頁的 **Full screen** 進入看板模式（Esc 離開）。

## 系統管理

「系統」= 各廠區包含哪些 Tag，由系統負責人在 `/systems` 維護（示範中所有人都可編輯，正式環境限負責人）。

- **編輯**：選廠區分頁，貼上 Tag 名稱按「檢查並加入」（FDM 找不到的會列出、不會加入），或從 FDM Tag 清單選取；下方即時顯示這個廠區依編輯中內容的燈號。按「儲存變更」才生效，並寫一筆變更紀錄（誰、何時、加入 / 移除哪些 Tag）。
- **引用**：燈號積木選「整個系統」時只記住「廠區 + 系統代號」，不複製 Tag 清單；系統改了，所有引用的積木與下鑽頁一起更新。
- **刪除**：內建系統不能刪；新增的系統還有頁面引用時不能刪，會列出是哪些頁面。
- 系統定義正式環境應存在 MIMIC 後端資料庫；示範版沒有後端，存在瀏覽器 localStorage（`mimic.systems.v1`）。

## FDM 取值時機

- **只在開啟網頁時一次、按重新整理時一次**（頂欄更新時間旁的按鈕、下鑽頁的 Refresh Values），不做定時自動更新。
- 每次先彙整需要的 Tag：所有系統定義裡的 Tag + 各頁面「選擇 Tag」燈號積木的 Tag，去除重複後**合成一次批次請求**（`fetchLatest`），所有頁面與積木共用這份結果。
- 取回後**集中算一次**所有廠區 × 系統的燈號（`buildRollup`），積木只查表；積木再多，計算量也不變。
- 例外：在燈號積木或系統管理**加入新 Tag** 時，只查這幾個新 Tag 並併入目前的資料，不重新取全部。
- 正式環境建議由 MIMIC 後端統一向 FDM 取值並暫存，不論多少使用者，FDM 每次只被呼叫一次。

## 燈號判定規則

前端不做門檻判斷，燈號完全依 FDM 回傳的旗標：

- 單一 Tag：沒有資料 → 灰；`isOOS` → 紅；`isOOC` → 黃；否則綠。
- 多個 Tag（燈號積木、廠區 × 系統）：任一紅 → 紅；否則任一黃 → 黃；否則有綠 → 綠；全部無資料 → 灰。
- 頁面（Explore 的圓點）彙整多個格子：紅 > 黃 > 灰 > 綠，有缺資料的頁面不報平安。

## 結構

```
src/catalog/catalog.ts  廠區、系統預設值、模擬 FDM 的 Tag、頁面目錄（含 Explore 資料）
src/lib/fdm.ts          FDM 資料來源（模擬，一次批次請求回傳 value / isOOS / isOOC）與 FDM Tag 主檔。接真實 API 只需替換 fetchLatest
src/lib/systems.ts      系統定義預設值、彙整要取值的 Tag、集中計算廠區 × 系統燈號（有測試）
src/lib/status.ts       依 FDM 旗標判定、彙整、規則文字（純函式，有測試）
src/state/              系統定義 / FDM / 頁面 / Favorites / UI 的 Context
src/pages/              DrillPage、ExplorePage、PageRoute、EditRoute、UserPageView、SystemsPage、SystemEditPage
src/components/         Layout、Sidebar、Topbar、Lamp 等
```

示範資料內建幾個情境：F18P2 超純水 3 OOS、2 OOC、1 無資料；F18P7 排氣整區無資料（灰）；F18P1 電力 TR1 溫度 97 °C 為 OOS（紅）。模擬 FDM 用 `catalog.ts` 各量測類型的界限產生 isOOS / isOOC，接上真實 FDM 後改由 FDM 判定。
